# Website Persea Agro Tani

Ini project React untuk website Persea Agro Tani. Panduan singkat cara jalankan dan upload.

## 1. Coba dulu di komputer (opsional)
```
npm install
npm run dev
```
Buka link yang muncul di terminal (biasanya http://localhost:5173).

## 2. Upload ke internet (gratis)

### Langkah A — Simpan ke GitHub
1. Buat akun di github.com (kalau belum punya)
2. Buat repository baru, nama bebas (misal: persea-agro-tani)
3. Upload semua file di folder ini ke repository itu

### Langkah B — Hubungkan ke Vercel
1. Buat akun di vercel.com, login pakai akun GitHub
2. Klik "Add New Project"
3. Pilih repository yang tadi dibuat
4. Klik "Deploy" — tunggu 1-2 menit
5. Selesai! Vercel akan kasih alamat website (contoh: persea-agro-tani.vercel.app)

Setiap kali ada perubahan yang di-upload ke GitHub, Vercel otomatis update website secara otomatis.

## Kalau mau pakai domain sendiri (misal perseaagrotani.com)
Beli domain di provider seperti Niagahoster atau Domainesia, lalu hubungkan ke Vercel lewat menu "Domains" di project settingnya.
